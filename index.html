      KARAOKETV

      1. Buka aplikasi di TV Android

      1. Pasang browser TV Bro (gratis, dioptimalkan untuk remote) dari Google Play di TV.
      2. Buka URL aplikasi ini di TV Bro.
      3. Simpan lewat menu Bookmark / Shortcut supaya tidak perlu mengetik URL lagi.
      4. Aktifkan voice search TV Bro bila remote Anda punya mikrofon — lebih cepat daripada mengetik.

      Catatan: fitur "Install PWA" tidak selalu tersedia di browser TV. Halaman tetap berjalan normal tanpa dipasang.

      2. Blokir iklan (2 lapis, gratis)

      Lapis 1 — AdGuard DNS (berlaku untuk seluruh TV):

      1. Masuk Setelan TV → Network & Internet → Private DNS.
      2. Pilih "Nama host penyedia DNS pribadi" lalu isi: dns.adguard-dns.com
      3. Simpan. Bila TV tidak memiliki menu Private DNS, isi DNS manual di router: 94.140.14.14 dan 94.140.15.15.

      Lapis 2 — aplikasi bersih: aplikasi ini memakai pemutar resmi youtube-nocookie.com dan tidak memasang iklan, tracker, maupun analytics sendiri.

      Yang perlu diketahui: iklan pre-roll/mid-roll dari YouTube sebagian masih bisa muncul karena berasal dari domain video yang sama dengan lagunya. Kedua lapis di atas menghilangkan iklan situs dan tracker, tetapi tidak menjamin 100% bebas iklan YouTube.

      3. API key YouTube (opsional tapi disarankan)

      Tanpa key, pencarian memakai server publik Invidious yang dapat berubah-ubah. Dengan key gratis, pencarian lebih cepat dan stabil (kuota 100 pencarian/hari).

      1. Buka console.cloud.google.com dengan akun Google Anda.
      2. Buat project baru, lalu buka APIs & Services → Library.
      3. Cari YouTube Data API v3 → klik Enable.
      4. Buka APIs & Services → Credentials → Create credentials → API key.
      5. Batasi: API restrictions = YouTube Data API v3; Application restrictions = Websites, isi https://*.github.io/* dan http://localhost/*.
      6. Salin key (AIza...), lalu tempel di Setelan aplikasi ini, atau simpan di file .env pada komputer.

      4. Mikrofon + echo (opsional)

      Untuk menyanyi, sambungkan mikrofon USB atau headset ke TV, lalu tekan tombol Mic di tab Putar. Gunakan headset bila mungkin agar tidak terjadi umpan balik (suara melengking).

      5. Kontrol dengan remote

      • Panah untuk berpindah fokus antar tombol.
      • OK untuk memilih.
      • Tombol angka 1-4 untuk pindah tab (Cari, Antre, Putar, Bantuan).
      • Back/Esc untuk menutup jendela Setelan atau keluar dari layar penuh.

      6. Batasan aplikasi

      • Kuota pencarian gratis 100/hari (fallback Invidious otomatis bila habis).
      • Antrean tersimpan di penyimpanan browser TV, bukan di server.
      • Lirik sudah menyatu di dalam video karaoke, jadi aplikasi tidak menambah panel lirik sendiri.

      Setelan

      Key disimpan hanya di browser TV ini. Kuota gratis: 100 pencarian/hari.
